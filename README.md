A full-stack **Retrieval-Augmented Generation (RAG)** platform that turns any user's documents into a domain-expert chatbot. Users upload their own files, web pages, images or voice, and get accurate, grounded answers drawn from *their* knowledge base.

---

## ✨ Features

- 📄 **Chat with your documents**: upload PDF, Word (.docx), PowerPoint (.pptx) and tabular datasets; content is parsed, chunked and embedded automatically
- 🌐 **Web ingestion**: scrape and index web pages into a user's knowledge base
- 🧠 **RAG pipeline**: MiniLM sentence-transformer embeddings + **ChromaDB** vector store for per-user semantic search, with answers generated by **Google Gemini**
- 🖼️ **Multimodal input**: image understanding (CLIP / vision route) and **voice input** transcribed with faster-whisper
- 💬 **Real-time chat UI** with persistent chat history
- 🔐 **Secure authentication**: email/password (bcrypt hashing) and **Google OAuth** sign-in
- 🔑 **API key management + embed endpoint**: let third-party sites integrate the chatbot securely
- ☁️ Deployed on **AWS**

---

## 🏗️ Architecture

~~~
 React frontend  ──►  FastAPI backend
 (chat UI, auth,       ├── routes/   chat · chats · ingest · datasets · vision · voice · api_keys · external
  uploads)             ├── rag/      file_parser → text_splitter → embedder → vector_store → pipeline
                       │             web_scrape
                       ├── ChromaDB  (per-user vector collections)
                       ├── SQL DB    (users, chats, API keys via SQLAlchemy)
                       └── Gemini    (answer generation over retrieved context)
~~~

**RAG flow:** upload → parse (PDF/DOCX/PPTX/web) → split into chunks → embed with MiniLM → store in ChromaDB → on each question, retrieve the top-k relevant chunks → Gemini generates a grounded answer.

## 🚀 Getting Started

**Backend**

~~~bash
cd chatbot-backend
python -m venv venv && source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
# create a .env file with your own GEMINI_API_KEY, database and SMTP settings
uvicorn main:app --reload
~~~

**Frontend**

~~~bash
cd chatbot-frontend
npm install
npm start
~~~

> ⚠️ Never commit your `.env` file. Keep API keys and passwords local.
